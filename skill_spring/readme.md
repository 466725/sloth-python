# skill_spring

This package is for learning and experimentation only. It contains standalone
examples and exercises, not production application features.

## Package boundary

- No feature outside `skill_spring` depends on this package.
- The website, backend APIs, stock analysis, alerts, and email notifications do
  not use this package.
- Keep learning examples self-contained. Do not introduce dependencies on this
  package from application code elsewhere in the repository.
- Changes to these examples are independent of application behavior.

Run examples explicitly when learning; they are not part of application startup
or deployment.
